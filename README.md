## 🎯 কীভাবে পড়বে?

1. প্রথমে প্রতিটি প্রশ্নের উত্তর বুঝে পড়বে।
2. কোড নিজে লিখে Visual Studio বা VS Code-এ রান করবে।
3. SQL Query SSMS-এ execute করে result যাচাই করবে।
4. Angular example নিজের Angular project-এ প্রয়োগ করবে।
5. প্রতিটি topic-এর ক্ষেত্রে কখন, কেন এবং কী trade-off আছে তা বোঝার চেষ্টা করবে।
